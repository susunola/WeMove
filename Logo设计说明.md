## 生成提示词

Use case: logo-brand. Design a single original symbol for a modern cloud-to-cloud file transfer desktop app, to be shown at 28px beside its name in a Linear-inspired light toolbar. Flat vector-style raster logo on genuinely transparent background. Two bold, softly rounded ribbon arrows interlock into one compact, balanced S-like exchange mark: upper ribbon travels right, lower ribbon travels left, with very clean negative space between them. Suggest reciprocal movement and dependable file transfer. Use ONLY solid cobalt blue #4776E6 and deep ink navy #25334B; no gradients, no shadows, no glow, no cloud outline, no letters, no text, no circular enclosing badge, no square tile background. Geometric but warm, elegant bespoke proportions, no tiny cuts or fussy details. Crisp smooth contours, consistent strong thickness, slightly rounded arrow tips. The symbol should occupy about 85 percent of a square canvas and be instantly legible at small sizes. Deliver one symbol only, centered, with transparent padding around it. No mockup, no stationery, no brand sheet.
