# WeMove UI concepts / 界面设计探索

Open `wemove-ui-concepts.html` in a browser. The file is self-contained and uses synthetic data only. It does not connect to cloud accounts or change the released interface.

- **A · Studio:** balanced light workspace with dual panes and a bottom queue.
- **B · Focus:** dark transfer-first console with speed and progress above compact file panes.
- **C · Finder:** neutral file workspace with a narrow navigation rail and a persistent task inspector.

Tabs, file selection, filtering, pause/resume, comparison messages, and clearing completed demo tasks work locally. Submit copies the design choice as JSON for pasting into the chat. The skill's bundled submit handler is unavailable in this installation; the prototype includes a local clipboard fallback. No receiver or background automation is installed.
