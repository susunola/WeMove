## 生成提示词

Use case: ui-mockup. Create a high-fidelity flat screenshot concept for a Chinese desktop cloud file transfer utility called 网盘搬运助手. Modern professional tool inspired by Linear's precise typography and restrained surfaces. Landscape 1536x1024 composition. UI is almost edge-to-edge with 12 px outer margin, NO fake macOS traffic lights, NO perspective, no device frame. Off-white slim 190px sidebar, white main workspace, hairline separators, charcoal typography, single royal-blue accent for progress. One compact top toolbar with app identity, Browse/Compare segmented switch, small 中文 language trigger, Compare and Incremental copy actions. Sidebar five cloud accounts 阿里云盘 夸克网盘 OneDrive 坚果云 百度网盘, modest provider icons, selected subtle gray row, bottom Settings and Cache. Upper workspace two equal BORDERLESS file lists separated only by a vertical hairline, larger bold provider headings, compact breadcrumbs and subtle search fields. Rows with clear dark file names, gray metadata, 40px row height. Files AlmaLinux-10.0.iso 6.8 GB, Rocky-9.6.iso 12.0 GB, VMware-ESXi.iso 401 MB, 安装说明.pdf 2.3 MB. Lower 35 percent is the visual focal point: 传输队列 with readable 16px header and subtle status '2 个任务正在传输'; grouped actions at right 清除已完成 全部开始 暂停全部. Three spacious task rows showing file name, source to destination, thin blue progress, state and speed and pause icon. One task 62% 17.7 MB/s, one queued, one complete muted green. Keep all actions plausible for an existing desktop transfer app. Crisp Chinese typography, enough contrast, warm-free gray palette. Avoid many rounded cards, colored badges everywhere, excessive shadows, decorative gradients, tiny unreadable text, dashboard statistic cards, huge empty whitespace, marketing hero. The image should look like an elegant shipped productivity app, realistic restrained design.
